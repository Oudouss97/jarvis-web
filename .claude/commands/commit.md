# /commit

**Objectif :** Sauvegarder rapidement tous les changements actuels dans Git.

**Mission :**
1. Vérifier si le dépôt git est initialisé. S'il ne l'est pas, proposer de faire `git init`.
2. Exécuter `git add .` pour inclure tous les fichiers modifiés et nouveaux.
3. Exécuter `git commit -m "[MESSAGE]"` en utilisant le texte fourni par l'utilisateur.
4. Confirmer la sauvegarde avec le hash du commit.
